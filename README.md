
# Biblioteca Entre Páginas

Projeto desenvolvido para a avaliação de Programação de Aplicativos.

## Sobre o projeto

O site apresenta uma biblioteca fictícia, alguns livros disponíveis e um formulário que calcula a data prevista para devolução de um livro.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionamento

O usuário informa seu nome e a quantidade de dias do empréstimo.

O sistema verifica os dados e apresenta a data prevista de devolução. Caso exista algum erro, uma mensagem aparece na tela.

## Regras

- O nome deve ser preenchido.
- A quantidade de dias deve ser um número inteiro.
- O prazo deve estar entre 1 e 30 dias.

## Testes

- Campos vazios: deve apresentar erro.
- Prazo 0: deve apresentar erro.
- Prazo 31: deve apresentar erro.
- Prazo 7: deve calcular a data corretamente.
